# Workout Log

A simple full-stack web application for creating, viewing, editing, and deleting workout records.

## Technologies

- Node.js
- Express
- MongoDB
- Mongoose
- Pug

## Workout Fields

- Exercise
- Sets
- Reps
- Weight
- Date
- Notes

## Setup

1. Clone the repository.

2. Enter the project directory:

   ```bash
   cd workout-log
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file:

   ```env
   PORT=3000
   MONGO_URI=your_mongodb_connection_string
   ```

5. Start the application:

   ```bash
   npm start
   ```

6. Open the application at:

   ```text
   http://localhost:3000/workouts
   ```
