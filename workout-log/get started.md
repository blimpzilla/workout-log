# Get Started

## Run these commands

1. Clone the repo
`git clone https://github.com/blimpzilla/workout-log`

2. go into project folder
`cd workout-log`

3. Install the current dependencies
`npm install`

4. Create an .env file these variables
`touch .env`
```

MONGO_URI=mongodb+srv://muhi0029_db_user:NB2fg8FW5q8njPDM@workoutlogcluster.vsb4cre.mongodb.net/?appName=WorkoutLogCluster
```

5. Start the project server
`npm start`

6. Open in your browser
`http://localhost:3000`
